# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that provides three useful tools through a simple menu. The tools are a Calculator, a To-Do List, and a Number Checker. The program uses functions, loops, lists, conditionals, and f-strings. It handles invalid choices and returns to the menu after each tool until the user chooses to quit.

## How to Run

1. Make sure Python 3 is installed.
2. Open Git Bash or a terminal in the project folder.
3. Run the following command:

   ```bash
   python toolkit.py
   ```
4. Choose a menu option from 1 to 4 and follow the prompts. Choose 4 to quit.

## Reflection

The hardest part of this assignment was connecting the three tools to one menu that keeps running until the user quits. The bug that took the longest to fix was a syntax error caused by an unterminated string in toolkit.py. I fixed it by correcting the code and testing the program again. Testing each menu option helped me understand how functions and loops work together. I also learned the importance of handling invalid input so the program does not crash. With one more week, I would add a password generator and improve the to-do list so users can remove completed tasks.
