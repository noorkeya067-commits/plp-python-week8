# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that provides three useful tools through a simple menu. The tools are a Calculator, a To-Do List, and a Number Checker. The To-Do List allows users to view, add, and delete tasks. The program uses functions, loops, lists, conditionals, and f-strings. It handles invalid choices and returns to the menu after each tool until the user chooses to quit.

## How to Run

1. Make sure Python 3 is installed.
2. Open Git Bash or a terminal in the project folder.
3. Run the following command:

   ```bash
   python toolkit.py
